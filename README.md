# vmaerten/tap

Homebrew casks for [ghl](https://github.com/vmaerten/ghl), a local Git review app for macOS on Apple Silicon.

```bash
brew install --cask vmaerten/tap/ghl
```

Name the cask in full: Homebrew only loads casks from a third-party tap once trusted, and installing by full name trusts this one. The cask is updated by each ghl release.
